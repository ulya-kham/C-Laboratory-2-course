## Задача 1

### Текст задачи

Точка координат.
Создайте сущность Точка, расположенную на двумерной плоскости, которая описывается:
• Координата Х: число
• Координата Y: число
• Может возвращать текстовое представление вида “{X;Y}”
Необходимо создать три точки с разными координатами и вывести на экран их текстовое
представление.

### Алгоритм решения
1. Создан класс Point (Точка). Поля - double _x и double _y (координаты точки). Конструктор по умолчанию, который присваивает координатам = 0. Конструктор с параметром, который передает double x и double y (координаты точки). Конструктор копирования другого объекта, который принимает его как параметр, с проверкой на попытку null значения (в этом случае 0;0), иначе скопирует значения у переданного объекта. Свойства для X Y, чтобы считать или записать значение. И текстоввое представление, позволяющее представить координаты в формает {x;y}
2. Решение задачи: Создаем точки через метод (CreatePoint(string number, Point point1, Point point2)), который передает номер точки и другие точки, и в нем есть использующийся метод IsDifferent, который позволяет проверить одинаковы ли точки. Если точки различны, то все хорошо. и все создается.
3. Демонстрация класса Точка: Создаем точку1 по умолчанию, затем точку2, которой потом передаем значения через клавиатуру - конструктор с параметрами. Точка3 - копия точки2 через конструктор копирования. Изменяем точку2 с помощью свойств и выводим все точки

# Задание 2

## Задача 1

### Текст задачи

Прямая.
Создайте сущность Линия, расположенную на двумерной плоскости, которая описывается:
• Координата начала: Точка
• Координата конца: Точка
• Может возвращать текстовое представление вида “Линия от {X1;Y1} до {X2;Y2}”
Для указания координат нужно использовать сущность Точка, разработанную в задании 1.1. Создайте
линии со следующими характеристиками:
1. Линия 1 с началом в т. {1;3} и концом в т.{23;8}.
2. Линия 2, горизонтальная, на высоте 10, от точки 5 до точки 25.
3. Линия 3, которая начинается всегда там же, где начинается линия 1, и заканчивается всегда там
же, где заканчивается линия 2. Таким образом, если положение первой или второй линии
меняется, то меняется и третья линия.
4. После создания всех трех объектов измените координаты первой и второй линий, причем
сделайте это таким образом, чтобы положение третьей линии соответствовало требованиям
пункта 3.
5. Измените координаты первой линии так, чтобы при этом не изменились, координаты третьей
линии

### Алгоритм решения
1. Создан класс Line (Линия). Поля - Point _start и Point _end (точки начала и конца линии). Конструктор по умолчанию создает две пустые точки. Конструктор с параметрами принимает две точки и присваивает их через свойства. Конструктор копирования принимает другую линию, проверяет на null (если null - создает пустые точки), иначе создает новые точки через конструктор копирования Point. Свойства Start и End с проверкой на null (если null - создается пустая точка, иначе копируется). ToString возвращает строку "Линия от {X1;Y1} до {X2;Y2}"
2. Решение задачи: Создаем три линии с заданными координатами. Линия1 с параметрами, которые создают новые точки с нужными координатами, Линия2 аналогично, Линия3 из начала Линии1(передаем Start линии1) и конца Линии2(передаем End линии2). Затем вводим новые координаты для Линии1 и Линии2 через метод ReadPoint, проверяя что они отличаются от старых. Обновляем свойства линий и заново присваиваем Линии3 ссылки на обновленные точки из Линии1 и Линии2. В конце меняем только Линию1(ее конец), не трогая Линию3. Если полностью помменять Линию1 - т.е. ее начало, то Линия3 - изменится. а нам по условию так нельзя. Линия3 - имеет начало такое же как Линия1.
3. Демонстрация класса Линия: Создаем линию1 по умолчанию, линию2 через ввод координат, линию3 как копию линии2. Изменяем линию2, показывая что линия3 не изменилась, потому что она не ссылается на линию2. Создаем линию4, присваиваем ей null (создается пустая точка), копируем координаты линии3, меняем начало линии4. Создаем линию5 из концов линии2 и линии4. Выводим все точки

# Задание 3

## Задача 1

### Текст задачи

Студент.
Создайте сущность Студент, которая описывается:
• Имя: строка
• Оценки: массив целых чисел.
• Может возвращать текстовое представление вида “Имя: [оценка1, оценка2,…,оценкаN]”
Необходимо выполнить следующие задачи:
1. Создать студента Васю с оценками: 3,4,5.
2. Создать студента Петю и скопировать оценки Васи, присвоив содержимое поля с
оценками Васи полю с оценками Пети.
3. Заменить первую оценку Пети на число 5. Вывести на экран строковое представление
Васи и Пети. Объяснить результат
4. Создать студента Андрея и скопировать ему оценки Васи так, чтобы изменение оценок
Васи не влияло на Андрея.

### Алгоритм решения
1. Создан класс Student (Студент). Поля - string _name (имя) и int[] _grades (массив оценок). Конструктор по умолчанию присваивает имя "Студент X" и пустой массив. Конструктор с параметрами принимает имя и массив оценок, присваивает через свойства. Конструктор копирования принимает другого студента, проверяет на null, иначе копирует имя и создает новый массив оценок с копированием всех элементов, не ссылается на тот же массив. Свойство Name с проверкой на пустую строку. Свойство Grades с проверкой на null и созданием нового массива с копированием элементов. ToString возвращает "Имя: [оценка1, оценка2,...,оценкаN]"
2. Решение задачи: Создаем Васю с оценками 3,4,5. Создаем Петю, передавая ему массив оценок Васи через конструктор (свойство Grades делает копию). Меняем первую оценку Пети на 5, выводим Васю и Петю. Так как Петя отельный объект, то оценки, которые он скопировал у Пети - это копия массива, а не массив Пети, поэтому когда мы у Пети поменяли оценку, то на Васю это не повлияло. Создаем Андрея с копией оценок Васи. Вводим новые оценки для Васи, присваиваем через свойство (создается новый массив). Выводим всех трех студентов, показывая что Андрей не изменился (у него своя копия массива)
3. Демонстрация класса Студент: Создаем студента1 по умолчанию, студента2 через ввод имени и оценок, студента3 как копию студента2. Меняем первую оценку студента2, показывая что студент3 не изменился. Меняем имя студента3. Присваиваем оценки студента2 = null (создается пустой массив). Вводим оценки для студента1 и всех студентов
